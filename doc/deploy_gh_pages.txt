Deployment
==========

The web app lives in www/ on the main branch and is published to gh-pages.

Automated deployment
--------------------
.github/workflows/release.yml publishes www/ to gh-pages on every push to
main. It can also be started manually from the Actions tab (workflow_dispatch).

Manual deployment (fallback)
----------------------------
If GitHub Actions is unavailable, sync the files manually:

git checkout main
mkdir tmp
copy -r .\www\* .\tmp\.
git checkout gh-pages
copy -r -Force .\tmp\* .
rm -r .\tmp\
git add .
git commit -m "sync to gh-pages"
git push
git checkout main
